Fetch & Matching

How it works

  1. The fetcher pulls Polymarket markets (sorted by volume) every N minutes.
  2. It calls The Odds API for live odds from Pinnacle (and any other bookmakers you add).
  3. A fuzzy-text matcher links each PM question to the best sportsbook event.
  4. Implied probabilities are compared: book_implied − pm_implied = edge.
  5. If pm_yes + book_no_implied < 1 (or the symmetric case), a true arb exists.
  6. All results appear in the Opportunities tab, sorted by edge size.

Auto-matching is heuristic — always verify the event match before placing a bet. Use the Markets tab to inspect and override matches manually.
